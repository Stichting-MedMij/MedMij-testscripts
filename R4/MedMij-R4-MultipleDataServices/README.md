# MedMij R4 MultipleDataServices

This folder contains a coherent R4 test record for the fictional patients **Gé Gevens-Dienst** and **Anton van Alles-Wat**.

## Data services

| Data service | Version | Gé | Anton |
| --- | --- | --- | --- |
| 66 - Vaccinations | 2.0.4 | Influenza and maternal pertussis | COVID-19, influenza and pneumococcal vaccinations |
| 68 - Medication Process 9 | 3.0.0-rc.3 | Asthma and pregnancy medication | Medication for diabetes, COPD and atrial fibrillation |

| 900000102-900000109 - Oral Health and MedMij Core | 1.0.0-rc.1 | Pregnancy-related gingivitis and preventive care | Poor oral health and a partial upper denture |

The resources are grouped by data service. All persons, organizations, identifiers and clinical data are fictional and intended only for exploratory, integration and functional testing. This is not qualification material.
